API Reference

CRD リファレンス

API グループは moco.cybozu.com/v1beta2 のみ（storage version）。CRD は MySQLCluster と BackupPolicy の 2 つです。conversion.go の Hub() は将来の多バージョン変換のためのマーカーで、現在 spoke バージョンはありません。

MySQLCluster — spec 全フィールド

フィールドデフォルト意味 / 制約

volumeClaimTemplates必須mysql-data という名前の claim が必須。各 claim に storage requests 必須

collectors空非空なら mysqld_exporter サイドカーを追加（collector flag 名のリスト）

生成されるリソース名の規則

Pod:            moco-<name>-<index>
StatefulSet / headless Service / SA / user Secret:  moco-<name>
Service:        moco-<name>-primary / moco-<name>-replica
my.cnf Secret:  moco-my-cnf-<name>
my.cnf ConfigMap: moco-<name>.<fnv32a hash>   (内容が変わると新しい名前で作られる)
controller 側 Secret:  mysql-<namespace>.<name>   (moco-system に置かれる)
gRPC 証明書:    moco-agent-<ns>.<name> (Certificate) → moco-<name>-grpc (Secret)
バックアップ:   moco-backup-<name> (CronJob/Role/RoleBinding)
リストア:       moco-restore-<name> (Job/Role/RoleBinding)
クラスタ名は 40 文字以下に制限されています（StatefulSet / CronJob 名の 52 文字制限から逆算）mysqlcluster_webhook.go#ValidateCreate。

Webhook による検証

タイミング検証内容
作成時 (mutating)finalizer moco.cybozu.com/mysqlcluster の付与、serverIDBase の採番
作成時 (validating)名前 40 文字以下 / mysql-data claim 必須 / replicas 正の奇数 / mysqld コンテナ必須 / 予約コンテナ名 (agent, slow-log, mysqld-exporter, moco-init)・予約ポート (3306, 33060, 33062, 9081)・予約 volume 名 (tmp, run, var-log, mysql-conf, mysql-init-conf, mysql-conf-secret, slow-log-agent-config) の使用禁止 / cron 形式の検証
更新時 (validating)replicas 減少禁止 / replicationSourceSecretName の追加・変更禁止 / restore 編集不可 / ボリューム拡張は StorageClass の allowVolumeExpansion を実際に確認して許可

BackupPolicy

status を持たない spec のみの namespace リソース。schedule（cron, 必須）、jobConfig、CronJob へ透過的にコピーされる timeZone / concurrencyPolicy（既定 Allow）/ startingDeadlineSeconds / successfulJobsHistoryLimit(3) / failedJobsHistoryLimit(1) / activeDeadlineSeconds / backoffLimit(6) を持ちます。MySQLCluster から参照されている間は削除できません（validating webhook が拒否）api/v1beta2/backuppolicy_webhook.go。

JobConfig / BucketConfig（backup と restore で共通）

フィールドデフォルト意味
serviceAccountName必須Job の SA。controller が Role/RoleBinding を紐づける
workVolume必須作業ディレクトリ。generic ephemeral volume 推奨、emptyDir 非推奨
threads / cpu / memory4 / 4 / 4Gimysqlsh・zstd の並列度と requests。maxCpu / maxMemory 未指定なら limits なし
bucketConfig—bucketName(必須), region, endpointURL, usePathStyle, backendType (s3 / gcs / azure), caCert
env / envFrom / affinity / volumes / volumeMounts—認証情報の注入や CA 証明書のマウントに使う
