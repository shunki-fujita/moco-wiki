Overview

MOCO — Kubernetes 上の MySQL オペレータ

この wiki は cybozu-go/moco（v0.36.0, main @ 40f54d72）と cybozu-go/moco-agent（v0.16.0, main）のソースコードを LLM が読んで生成した内部構造ドキュメントです。記述にはソースの参照位置（ファイル / 関数名）を付記しています。

MOCO は Cybozu が開発する MySQL オペレータで、GTID ベースのロスレス準同期レプリケーションによる MySQL クラスタを Kubernetes 上で管理します。制約の多い group replication は採用せず、標準 MySQL との互換性を重視しています。

設計上の 3 つの性質

性質内容
互換性標準の MySQL semi-sync replication をそのまま使う。group replication は使わない
安全性書き込みは常に単一 primary のみ。errant transaction を検出し、そのレプリカを隔離する
可用性primary 障害時の自動 failover、Pod 再起動時の自動 switchover。1 クラスタ最大 5 インスタンス（正の奇数）

主な機能

MySQLCluster CR ごとの StatefulSet / Service / Secret / PDB などの自動管理、switchover / failover、mysqlsh によるバックアップと Point-in-Time Recovery、partition 制御による安全な MySQL バージョンアップ、外部 MySQL からのレプリケーション（intermediate primary）、kubectl-moco プラグイン。

対応バージョン: MySQL 8.0.28 / 8.0.43–45 / 8.4.4 / 8.4.8（LTS のみ）、Kubernetes 1.33–1.35。
